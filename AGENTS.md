# AGENTS.md

## Agent skills

### Трекер задач

Задачи хранятся как локальные markdown-файлы в `.scratch/<feature-slug>/`. См. `docs/agents/issue-tracker.md`.

### Метки триажа

Пять канонических ролей, строки меток совпадают с именами (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). См. `docs/agents/triage-labels.md`.

### Доменные документы

Один контекст (один `GLOSSARY.md` + `docs/adr/` в корне репозитория). См. `docs/agents/domain.md`.
