# Метки триажа

Скиллы оперируют пятью каноническими ролями триажа. Этот файл сопоставляет эти роли с реальными строками меток, используемыми в трекере задач этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                      |
| ------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить эту задачу          |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительной информации      |
| `ready-for-agent`         | `ready-for-agent`     | Полностью специфицировано, готово для AFK-агента |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком                  |
| `wontfix`                 | `wontfix`             | Не будет реализовано                          |

Когда скилл упоминает роль (например, «применить метку AFK-ready triage»), используйте соответствующую строку метки из этой таблицы.

Правьте колонку «Метка в нашем трекере» под тот словарь, который реально используете.
