# 02: Выделить библиотечный крейт и чистый домен

**What to build:** Вынести доменные правила Таймера, Account, локального времени
и Ledger в чистый слой без ввода-вывода, доступный как из бинарника, так и для
быстрых тестов. Пользователь не замечает изменений: CLI, вывод, коды выхода,
записи Ledger и обработка сна остаются прежними.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Появляется библиотечный крейт рядом с тонким бинарником; имя и путь
      бинарника `t` не меняются, `CARGO_BIN_EXE_t` продолжает работать.
- [x] Домен разложен на модули `account`, `time`, `status`, `ledger`,
      оформленные файлом `<модуль>.rs` рядом с одноимённой директорией, без
      `mod.rs`.
- [x] `Account` валидируется один раз конструктором; невалидный Account нельзя
      создать и передать вглубь.
- [x] Локальное время представлено явными типами, а не смесью `u64` минут и
      строк; метка Ledger представлена отдельным типом без новых проверок
      формата, диапазона и непустоты.
- [x] Состояние Таймера формируется чистой функцией в формате
      `HH:MM => HH:MM => HH:MM` с округлением остатка вверх до минуты.
- [x] Формат записей `i`/`o` и правило «предыдущий Учитываемый период не
      закрыт» живут в домене.
- [x] Домен не импортирует `std::fs`, `std::process`, `zbus` и `ctrlc`.
- [x] Запрет `unsafe` включён в библиотечном и бинарном крейтах.
- [x] Unit-тесты `Account` покрывают один и несколько сегментов,
      подчёркивания, цифры не в первой позиции, Unicode, разный регистр,
      ключевые слова Rust, одиночное подчёркивание, raw-идентификаторы,
      пустые сегменты, цифру в начале, пробелы и новые строки.
- [x] Unit-тесты `MinuteOfDay` покрывают разбор, диапазон и форматирование;
      `Timestamp` — сохранение обрезанной метки без дополнительной валидации.
- [x] Unit-тесты `TimerStatus` покрывают точный формат, округление остатка
      вверх и нулевой остаток при любом финальном отображении.
- [x] Unit-тесты `LedgerEntry` покрывают точный формат `i`/`o` и обнаружение
      незакрытого периода, включая пустые и завершающие пустые строки.
- [x] Тесты домена написаны до или вместе с реализацией, не запускают процесс
      и не ждут реального времени.
- [x] Наблюдаемое поведение не изменилось, существующие integration-тесты не
      редактировались и проходят.
- [x] Форматирование, сборка, clippy с запретом предупреждений и полный набор
      тестов проходят.
