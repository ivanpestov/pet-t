# 02: Выделить библиотечный крейт и чистый домен

**What to build:** Вынести доменные правила Таймера, Account, локального времени
и Ledger в чистый слой без ввода-вывода, доступный как из бинарника, так и для
быстрых тестов. Пользователь не замечает изменений: CLI, вывод, коды выхода,
записи Ledger и обработка сна остаются прежними.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Появляется библиотечный крейт рядом с тонким бинарником; имя и путь
      бинарника `t` не меняются, `CARGO_BIN_EXE_t` продолжает работать.
- [ ] Домен разложен на модули `account`, `time`, `status`, `ledger`,
      оформленные файлом `<модуль>.rs` рядом с одноимённой директорией, без
      `mod.rs`.
- [ ] `Account` валидируется один раз конструктором; невалидный Account нельзя
      создать и передать вглубь.
- [ ] Локальное время представлено явными типами, а не смесью `u64` минут и
      строк; метка Ledger представлена отдельным типом.
- [ ] Состояние Таймера формируется чистой функцией в формате
      `HH:MM => HH:MM => HH:MM` с округлением остатка вверх до минуты.
- [ ] Формат записей `i`/`o` и правило «предыдущий Учитываемый период не
      закрыт» живут в домене.
- [ ] Домен не импортирует `std::fs`, `std::process`, `zbus` и `ctrlc`.
- [ ] В библиотечном крейте включён запрет `unsafe`.
- [ ] Наблюдаемое поведение не изменилось, существующие integration-тесты не
      редактировались и проходят.
- [ ] Форматирование, сборка, clippy с запретом предупреждений и полный набор
      тестов проходят.
