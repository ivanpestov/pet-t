# 01: Унифицировать добавление записей в ledger

**What to build:** Начальная и завершающая записи Учитываемого периода добавляются через общую операцию, которая сбрасывает буфер и формирует понятную ошибку с контекстом файла. Для пользователя сохраняется текущее поведение Таймера, а ошибки записи остаются явными при любом способе завершения.

**Blocked by:** None (can start immediately).

- [ ] Начальная и завершающая записи используют одну общую операцию добавления, сброса буфера и формирования контекстной ошибки.
- [ ] Внешние проверки через собранный CLI подтверждают создание пары записей при естественном завершении и закрытие активного периода при Ctrl+C.
- [ ] Ошибка завершающей записи выводится явно и даёт код 1; при естественном завершении попытка уведомления всё равно выполняется.
- [ ] Форматирование, сборка, clippy с запретом предупреждений и стандартный запуск тестов проходят успешно.
