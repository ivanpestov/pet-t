# 02: Проверять Account по полным правилам идентификаторов Rust

**What to build:** Пользователь может записывать Учитываемые периоды в иерархический Account, включая Unicode-сегменты. Недопустимый Account отклоняется до открытия ledger: команда показывает краткую справку, возвращает код 2 и не создаёт либо не изменяет файл.

**Blocked by:** None (can start immediately).

- [ ] Принимаются одиночные и иерархические Account, сегменты которых соответствуют обычным идентификаторам Rust, включая Unicode, подчёркивания и цифры не на первой позиции.
- [ ] Отклоняются ключевые слова Rust, одиночное подчёркивание, raw-идентификаторы, пустые сегменты, цифра в начале сегмента, пробелы, новые строки и посторонние символы.
- [ ] Недопустимый Account возвращает код 2 с краткой справкой и не приводит к созданию или изменению ledger.
- [ ] Допустимый Account записывается целиком и без Payee.
- [ ] Правила Unicode реализованы через прямую зависимость unicode-ident.
- [ ] Форматирование, сборка, clippy с запретом предупреждений и стандартный запуск тестов проходят успешно.
