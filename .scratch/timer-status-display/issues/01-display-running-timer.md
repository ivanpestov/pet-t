# 01: Показывать состояние работающего Таймера

**What to build:** Пользователь видит текущее состояние Таймера как локальное время старта, остаток и Планируемое время завершения в едином формате HH:MM. Состояние появляется сразу после успешного запуска и обновляется на одной строке раз в минуту.

**Blocked by:** None (can start immediately).

- [ ] Начальное и обновляемое состояние имеет вид `<время старта> => <остаток> => <Планируемое время завершения>` с форматом HH:MM для всех значений.
- [ ] Время старта фиксируется один раз, а Планируемое время завершения вычисляется из него и заданной длительности.
- [ ] Начальный остаток равен заданной длительности; длительности больше часа отображаются в часах и минутах.
- [ ] Остаток вычисляется по монотонному сроку завершения, округляется вверх до целой минуты и не становится 00:00 раньше естественного завершения.
- [ ] Состояние обновляется на одной строке раз в минуту и не содержит Account.
- [ ] Внешние CLI-проверки покрывают начальное состояние, минутное обновление, округление и длительность больше часа через существующий seam собранного бинарника.
- [ ] Форматирование, сборка, clippy с запретом предупреждений и стандартный запуск тестов проходят успешно.
