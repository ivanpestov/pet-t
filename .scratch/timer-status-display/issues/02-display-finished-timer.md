# 02: Показывать итоговое состояние Таймера

**What to build:** После остановки пользователь видит итоговое состояние с Фактическим временем завершения вместо Планируемого. Естественное окончание показывает нулевой остаток, а досрочная или нештатная остановка сохраняет остаток на момент события.

**Blocked by:** 01 — Показывать состояние работающего Таймера.

- [ ] При естественном завершении отображается остаток 00:00 и Фактическое время завершения, после чего выводится перевод строки.
- [ ] При Ctrl+C отображаются остаток на момент остановки и Фактическое время завершения; код выхода остаётся 130.
- [ ] При suspend и ошибках во время работы используются те же правила итогового состояния без изменения существующих кодов выхода и диагностики.
- [ ] Фактическое время завершения фиксируется при обработке события остановки до попытки закрыть Учитываемый период.
- [ ] Ошибка запуска до появления начального состояния не создаёт итогового состояния.
- [ ] Уведомления, формат ledger-записей и их метки времени не изменяются.
- [ ] Внешние CLI-проверки покрывают естественное завершение, SIGINT и ошибку запуска через существующий seam собранного бинарника.
- [ ] Ручной сценарий с реальным suspend подтверждает итоговый остаток, Фактическое время завершения и сохранение поведения ledger; автоматические тесты не переводят систему в сон.
- [ ] Форматирование, сборка, clippy с запретом предупреждений и стандартный запуск всех тестов проходят успешно.
